Evite reutilização excessiva.

Use estas regras:

* a imagem principal de uma página de serviço não deve ser a mesma imagem principal de outra página;
* o Hero principal deve permanecer exclusivo da homepage;
* cards podem usar imagens diferentes das imagens principais das páginas;
* uma imagem pode aparecer em mais de uma página somente quando houver justificativa clara;
* não use uma mesma imagem em mais de três contextos;
* imagens de galeria podem ser reutilizadas com mais liberdade, desde que não provoquem repetição visual perceptível;
* priorize variedade de veículos, ângulos, horários e etapas do atendimento.

Registre qualquer reutilização prevista.

## 5. ALT TEXT

Crie alt text específico para cada imagem que será publicada.

Regras:

* descrever o que realmente aparece;
* usar linguagem natural;
* não repetir mecanicamente o nome do arquivo;
* incluir Marcus Reboque somente quando ajudar a identificar a operação;
* incluir Fortaleza apenas quando o contexto local for legítimo;
* evitar keyword stuffing;
* não usar “imagem de” ou “foto de”, salvo necessidade;
* não inventar bairro, cidade, modelo, situação ou equipamento;
* não afirmar emergência quando a cena não comprovar;
* limitar preferencialmente a aproximadamente 125 caracteres;
* alt vazio apenas para imagem puramente decorativa.

Exemplo adequado:

Caminhonete sendo transportada em caminhão plataforma da Marcus Reboque em Fortaleza

Exemplo inadequado:

Guincho Fortaleza barato 24 horas reboque perto de mim caminhonete Fortaleza Ceará
