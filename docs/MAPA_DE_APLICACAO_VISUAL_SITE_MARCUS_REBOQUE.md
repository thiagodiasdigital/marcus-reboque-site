## Estrategia visual

- Usar fotos reais de atendimento como prova operacional, sem transformar imagens de avaria em decoracao generica.
- Manter uma imagem principal exclusiva para cada pagina de servico com cobertura fotografica.
- Usar cards diferentes das imagens principais sempre que houver acervo suficiente.
- Deixar `transporte de utilitarios` como pendencia visual: usar placeholder institucional, nao foto de outra categoria.
- Preservar o logotipo como ativo institucional recorrente; para fotos operacionais, limitar reutilizacao a no maximo tres contextos.

### Hero desktop/mobile

- Hero principal: #064 `IMAGENS_MARCUS_REBOQUE/02_HERO/marcus-reboque-hero-guincho-caminhonete-fortaleza-ce-03.webp`
- Adequacao desktop: boa para hero com overlay escuro; resolucao atual e moderada, entao evitar zoom agressivo.
- Adequacao mobile: exige versao mobile futura ou recorte controlado em 4:5, com foco na picape e na plataforma.
- Lado recomendado para texto: esquerda superior ou centro-esquerda, com gradiente escuro para leitura.
- Ponto focal: picape cinza e caminhao plataforma, mantendo a cabine visivel.
- Area segura para recorte: centro e centro-direita; evitar cortar a traseira da plataforma e a cabine.
- Scroll motion: viavel com parallax leve e escala baixa; nao usar deslocamento que corte o veiculo.
- Contraste: aplicar overlay escuro de 35% a 55% ou camada linear no lado do texto.
