# Marcus Reboque

Fundacao tecnica do site Marcus Reboque em Next.js App Router.

## Comandos

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```

## Variaveis

Copie as chaves de `.env.example` para o ambiente real quando houver dominio definido. Por padrao, `NEXT_PUBLIC_INDEXABLE=false` bloqueia indexacao e remove URLs do sitemap.

## Escopo atual

- Homepage minima tecnica, sem layout comercial final.
- Conteudo institucional centralizado em `src/content/`.
- Imagens publicas copiadas a partir de ativos aprovados em `IMAGENS_MARCUS_REBOQUE/`.
- Pendencias visuais mantidas fora de `public/`.
